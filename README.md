# txtmap

`txtmap` is a parsing tool for `txtstar`, a custom plaintext format with internal and external links.

## Development

`txtmap` is built using [Rust 1.99.1](https://releases.rs/docs/1.99.1/).

[`qoomon/git-conventional-commits`](https://github.com/qoomon/git-conventional-commits) is used in the development process in order to enforce conventional commits.
